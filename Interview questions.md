1. In android manifest.xml file what is exported true and exported false means ?

Ans :-
- if android:exported="true" The component can be accessed by other applications.
Example : Google Pay allows Flipkart to launch its payment Activity to initiate the payment.
- if android:exported="false" The component is generally accessible only within your application.
Example : Other apps cannot directly launch Google Pay's internal PIN verification Activity
